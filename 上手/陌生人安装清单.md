# 陌生人安装清单 · 从 clone 到 QQ 里收到回话

> 给**第一次看到这个仓库**的人。
> 你不需要读源码。照着走，**总共只有一步需要你动手：扫码。**
> 本文所有数字都标了实测日期与机器；没实测的会明确写「未实测」。

---

## 0. 先说清楚你会经历什么

| 阶段 | 谁干 | 大概多久 | 实测依据 |
|---|---|---|---|
| 克隆 + 跑自检 | 机器 | 约 30 秒 | 2026-11-02 · Win10 · Node 24.16 · 实测 27.0s |
| 找本机浏览器、开独立窗口 | 机器 | 约 6 秒 | 2026-11-02 实测 6.3s（Edge 156） |
| **扫码登录 QQ 开放平台** | **你（唯一动手）** | 看你手速 | 未实测（臣没在陌生人机上扫过） |
| 建机器人、抄凭据、写配置、验令牌、起网关 | 机器 | 约 1 分钟 | 未实测全链（分段已通，见 §5） |
| 在 QQ 里说第一句话，看它回 | 你 | 2 秒 | 2026-11-02 10:51 实测端到端 2.2s |

**一句话**：一条命令，然后手机 QQ 扫一下，剩下机器干。

## 1. 前置条件（不满足就先补，不然卡在第 2 步）

| 要求 | 怎么自查 | 不满足会怎样 |
|---|---|---|
| **Node.js ≥ 22** | `node -v` | 起不来。内核十层在 ≥18 上也能跑，但 QQ 网关与扫码浏览器要靠 Node 22 的全局 `fetch`/`WebSocket`——18/20 会一直绿到「扫码」那一步才崩，所以按 22 要求 |
| **本机有一个 Chromium 内核浏览器** | Windows 10/11 自带 Edge，**一般不用管** | 脚本会报「找不到浏览器」。装 Edge 或 Chrome 即可，不会让你下载任何东西 |
| **一个 QQ 号** | —— | 机器人挂在它的名下，将来删号=删机器人 |
| **能打开 <https://q.qq.com>** | 浏览器试一下 | 会卡在扫码后的跳转 |

> ⛔ 不需要 `npm install`。运行时 npm 依赖 **0 个**。随包模型与 WASM 运行集都在仓库里。

## 2. 主路径：一条命令（推荐）

### 2.1 克隆

```bash
git clone <本仓库地址> 鲸鱼　　　← 地址见仓库首页右上角「Code」按钮
cd 鲸鱼
```

### 2.2 先确认内核是好的（30 秒）

```bash
npm run selfcheck
```

**你该看见**：十三层逐层打勾，最后一行 `总耗时 · ｜ 退出码 0`。
（其中 L3 的 R@5 六条、L11 的装机那组，在本机缺跨项目语料/没装 DSH 时会标「跳过」——条数照发、不算失败。）
**这一步失败就停下**——那是环境问题，不是安装问题，后面不用试。

> 顺便说：这一步不连网、不碰 QQ、不写你任何数据。

### 2.3 跑安装器

```bash
node 适配器/qq/安装/一键装.js
```

**它会做这些事，你会在屏幕上按顺序看到**：

```
🐋 会记得你的鲸鱼 · 一键装（登录 → 建机器人 → 拿凭据 → 写配置 → 验令牌 → 起网关）
· 浏览器：Edge（C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe）
✅ 起窗口：通过 —— 新窗口 · 端口 9335 · profile …\配置\浏览器配置-新号
❌ 判登录态：失败 —— 未登录 —— 腾讯把后台入口重定向到了登录页（login.html）

  ───────── 请在弹出的窗口里扫码登录（本流程只有这一步需要你）─────────
   用要挂机器人的那个 QQ 号扫。扫完什么都不用点，我这边每 2 秒看一眼。
  ────────────────────────────────────────────────────────────────

👉 需要你动手（第 1 次，也是唯一需要人的地方）
```

### 2.4 你现在要做的唯一一件事

打开那个自动弹出的 Edge 窗口 → 用**手机 QQ** 扫窗口里的二维码 → 手机上点「允许」。

**扫完什么都不用点。** 脚本自己会往下走。

> ⏱️ 它默认等你 **900 秒**（15 分钟）。超时会以**退出码 3** 结束，窗口留着、登录态也在——
> **直接重跑同一条命令即可**，不用重新扫码。想等久点：`--超时 1800`。

> 📷 这个窗口是**独立的浏览器配置**（`配置/浏览器配置-新号`），
> 不碰你日常浏览器的 cookie 和标签页，所以你**不用关自己正在用的浏览器**。
> 代价是首次必须扫一次；cookie 留在独立配置里，**第二次起免扫**。

### 2.5 然后机器接手，你会看到

> ⚠️ 下面这段是按代码路径写的**预期输出**（2026-11-02 未在陌生人机上完整跑过全链，
> 只验到「等扫码」那一行）。如果你看到的与它差很多，那是文档错了，不是你的错——麻烦开 issue。

```
✅ 代建：通过 —— 建成了 <你的AppID>（一键直建）
✅ 写配置：通过 —— 已写 配置/qq.json 并回读逐字相符
✅ 验令牌：通过 —— access_token 到手，有效期 7200 秒
✅ 起常驻网关：通过 —— READY · 机器人 <名字>

  ┌─ 收尾账 ────────────────────────────────────────────
  │ 人动手次数：1（扫码 xx 秒）
  │ 机器步数：  7 步 · 总耗时 xx 秒
  │ AppID：     <你的AppID>（Secret sk****）
  │ 日志：      …\临时\一键装日志.json
  └────────────────────────────────────────────────────

🎉 一键装全链通过。下一步：在 QQ 里对机器人说一句话，看它回不回第一句。
```

**看到 🎉 就是装完了。** 机器人在跑（常驻进程）。

### 2.6 去 QQ 里说第一句话

打开手机 QQ → 找到你刚建的机器人 → 发一句话，比如「我叫什么」。
**你该看见**：它会回。第一次问它记不住是正常的（你还没告诉过它什么）。

试这一句，验它**能翻原话**：

```
第 1 句：我最喜欢的动物是猫，叫豆豆
（等它回）
第 2 句：我最喜欢什么动物
```

它应该答出「猫，叫豆豆」。

## 3. 备路径：我手上已经有 AppID 和 AppSecret

如果你已经自己在 <https://q.qq.com> 建好机器人、抄到了两个凭据：

```bash
# 1. 复制模板
cp 配置/qq.example.json 配置/qq.json      # Windows: copy 配置\qq.example.json 配置\qq.json

# 2. 编辑 配置/qq.json，把 appId / appSecret 换成真的

# 3. 三层裸测（不写数据、不发消息）
npm run qq:dry
```

`--dry` 只验三件事：**凭据真不真 → 令牌换不换得到 → 网关能不能 READY**。
通过 = `✅ dry 通过，退出码 0`；失败退出码 **1**（脚本/CI 里可以直接判）。

三层过了再正式跑：

```bash
npm run qq
```

## 4. 装完必做：给它一个会说话的模型（否则它只会念原话）

**不做这一步也能跑**，但机器人只会「把相关原话念给你听」，不会闲聊。这是有意的降级，不是故障。

```bash
cp 配置/llm.example.json 配置/llm.json
```

编辑 `配置/llm.json`：

```json
{
  "地址": "https://api.deepseek.com/v1/chat/completions",
  "密钥": "sk-你的key",
  "模型": "deepseek-chat"
}
```

任何 OpenAI 兼容服务都行（DeepSeek / 通义 / 智谱 / 本地 Ollama）。
`配置/llm.json` 已被 `.gitignore` 挡住，**永远不会进仓库**。

改完重启网关（再跑一次 `node 适配器/qq/安装/一键装.js --不建` 即可，已登录+有凭据时会走快路）。

启动第一屏会直接报到钱从哪来，不用猜：

```
OK  模型 deepseek-chat · key sk-**** · 来源：配置文件 …\配置\llm.json
```

## 6. 卡住了看这里

| 现象 | 原因 | 动作 |
|---|---|---|
| `❌ 找不到 Chromium 内核浏览器` | 本机没 Edge/Chrome | 装 Edge（免费的） |
| 扫码后窗口一直不跳转 | 网络断在 q.qq.com | 确认 <https://q.qq.com> 能打开 |
| `❌ 判登录态：失败 —— 未登录` 反复出现 | 你扫的是**别的 QQ 号** | 用「将来要挂机器人的那个号」扫 |
| `❌ 验令牌：失败` | AppSecret 是假的/机器人被删了 | 重跑安装器（`--建后等 60` 给页面多点时间） |
| `npm run qq:dry` 报 4004 / Authentication fail | 用了网上旧教程的鉴权格式 | 本项目已用新格式（`QQBot {token}`），**别照 2024/2025 的教程改代码** |
| 日志刷「退避 Xs 后重连」 | 网络抖或令牌被别处换掉 | 正常自愈，超过 5 次再查网络 |
| 群里 @ 它没反应 | 机器人没上线 / 没拉进群 | 后台点「上线」，再拉进群 |
| 它答得很空、不像记得 | 没配 llm.json（走降级） | 见 §4 |

### 安装器退出码对照（自己排错时看这个）

| 码 | 意思 | 你该做什么 |
|---|---|---|
| `0` | 全链通过 | 去 QQ 里说话 |
| `1` | 崩了，或浏览器/窗口/后台没起来 | 把 `临时/一键装日志.json` 的「结论」发出来 |
| **`3`** | **等扫码超时（默认 900 秒）** | **直接重跑，不用重扫** |
| `4` | 代建没拿到凭据 | 重跑；实在不行 `--建后等 60` 给页面多点时间 |
| `5` | 写配置/回读不符 | 看 `配置/` 是否有写权限 |
| `6` | 令牌验不通 | 凭据假/失效；重跑重建一个机器人 |
| `7` | 网关没 READY | 查网络；或先 `npm run qq:dry` 看哪层断 |

## 7. ⚠️ 三条你必须先知道的硬限制（不是 bug，是腾讯的）

1. **一具机器人只能给创建人自己用。**
   实测原话：`该机器人仅供创建人使用，暂不支持进入群聊`。
   想给别人用 → **别人自己扫码建自己的**。这条路谁也代不了。

2. **AppSecret 只在「创建成功那一屏」明文出现一次。**
   之后永久掩码。腾讯那个「查看」按钮**是重置入口，不可逆**——所以安装器写死了一条禁令：**永不点「查看 AppSecret」**。
   抄丢了怎么办？让安装器**再建一个**（旧的删掉）。别点查看。

3. **主动开口有配额，被动回复不受限。**
   你说话 → 它接话：不受限。
   它自己想找你 → 一天一句，超了平台拒，记日志不重试。
   所以「她会忽然想起你」在 QQ 上**不能按原样跑**——本项目的选择是：宁可少说，不冒险。

## 10. 卸载 / 反悔

```bash
# 只是不想跑了：关掉常驻网关进程
# （Windows：任务管理器里找 node.exe，或）
taskkill /f /im node.exe     # ⚠️ 会杀你本机所有 node，确认再执行

# 要彻底清干净：
# 1. 后台 <https://q.qq.com> 删掉机器人
# 2. 删掉 配置/qq.json、配置/llm.json、配置/浏览器配置-新号/
# 3. 删掉 数据/（对话原文表与向量库都在这里）
# 4. 删掉整个克隆目录
```

你的对话数据全部在本地 `数据/` 目录，**没有一个字节上传到任何服务器**（除了你选的 LLM 服务）。
