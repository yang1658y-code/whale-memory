# 模型来源与许可

## bge-small-zh-v1.5（int8 量化）

| 项 | 值 |
|---|---|
| 原始模型 | `BAAI/bge-small-zh-v1.5`（北京智源人工智能研究院） |
| 本目录来源 | `Xenova/bge-small-zh-v1.5` 的 ONNX 转换版（ONNX Community 转换） |
| 量化方式 | 动态 int8（`model_quantized.onnx`，22.90 MB） |
| 许可证 | **MIT** |
| 结构 | 4 层 BERT，hidden 512，8 头，词表 21128，max_position 512 |
| 输出维度 | **512** |
| 池化口径 | **CLS**（last_hidden_state 第 0 位）+ L2 归一。bge 官方口径 |

### 文件清单

```
config.json              模型结构参数
tokenizer.json           词表 + 归一化/预切/WordPiece 规则（分词唯一事实源）
tokenizer_config.json    BertTokenizer 元信息（do_lower_case=false）
onnx/model_quantized.onnx   int8 权重
```

### 为什么是这个模型

600 条对话记录 / 50 条查询实测（与上游 L3 基线同口径）：

- 单路 R@5 72%、R@1 60%（打平上游 L3 基线）
- 加 BM25 RRF 后 R@5 84%
- 用 40MB 拿到了 2.2GB 的 BGE-M3 的约 89% 效果
- **「主动提一句」看 R@1** —— 这个核心动作上它一分不亏

### 升级 / 替换步骤

1. 把新的 `model_quantized.onnx` + `tokenizer.json` + `config.json` 覆盖到本目录
2. 改 `内核/向量小模型.js` 顶部的 `模型ID` 与 `维度` 两个常量（若维度不是 512）
3. **同步改 `配置/门控策略.json` 的 `标定` 段**（模型名 / 维度）——不改会被标定自检判为不符，强制降 quiet
4. `node 验收/向量小模型验收.js` 全绿才算换完
